# Montgomery Fleet Equipment Analysis using Excel

## About the Project

This project is an Excel-based analysis of Montgomery County fleet equipment inventory data.

I worked on this project as part of an Excel data analysis course, where the main focus was to practice cleaning a dataset and then using Excel tools to understand the data.

The project includes data cleaning, basic calculations and PivotTable analysis.

## What I Worked On

I used Excel to:

- Check the dataset for blank values
- Check and remove duplicate records
- Clean inconsistent formatting
- Remove unnecessary spaces from the data
- Adjust column widths and formatting
- Convert the dataset into an Excel Table
- Calculate basic summary statistics
- Create PivotTables to understand equipment distribution

## Dataset

The dataset contains fleet equipment information with three main columns:

- Department
- Equipment Class
- Equipment Count

The final dataset contains **129 records**.

## PivotTable Analysis

### Pivot Table 1 — Equipment by Department

I created a PivotTable to see how equipment is distributed across different departments.

The departments were sorted based on their total equipment count so that the distribution could be compared more easily.

### Pivot Table 2 — Department and Equipment Class

I added Equipment Class below Department to look at the equipment distribution in more detail.

I also used the PivotTable expand/collapse feature to focus on the **Transportation** department.

### Pivot Table 3 — Equipment Class and Department

For the third PivotTable, I placed Equipment Class above Department.

I used the expand/collapse option to focus on the **CUV** equipment class and see which departments had CUV equipment.
